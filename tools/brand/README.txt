COMBOCROWN - LOGO A IKONY / LOGO AND ICONS
==========================================

BARVY / COLOURS
  Zlata / Gold ........ #D0AE6B   (hover #E3C486)
  Cerna / Black ....... #000000   (logo pozadi / logo background)
  Tmave pozadi / Dark . #15161A   (aplikace, web / app, website)
  Text na svetle ...... #1B1B1F
  Seda / Grey text .... #A9ADB8
  Ramecek ikony ....... #342D1E   (beta: #C6C6CF)
  Pismo / Font ........ Segoe UI Bold (nazev ComboCrown), v souborech prevedene na krivky
  Znacka se pise vzdy "vavr0s" (male v, nula).

SLOZKY / FOLDERS
  svg\        vektory - libovolna velikost, do tisku, na web, do grafickych programu
              crown-*      samotna koruna (zlata / bila / cerna), pruhledne pozadi
              icon*        ikona aplikace (cerna) a bety (bila), 256x256
              logo-*       koruna + nazev ComboCrown: gold = na tmave pozadi, on-light = na svetle,
                           white / black = jednobarevne
  png\crown\  koruna v sirkach 64-2048 px, pruhledne
  png\icon\   ikona aplikace a bety 16-1024 px (16/32/48 jsou rucne ladene obrazky z aplikace)
  png\logo\   logo s nazvem v sirkach 400-3200 px, pruhledne
  ico\        Windows ikony (16-256 px v jednom souboru)
  web\        favicon.ico, favicon-32.png, apple-touch-icon.png (180), android-chrome-192/512.png,
              og-image.png 1200x630 (nahled odkazu na Discordu, Facebooku...)
  social\     discord-server-icon-512.png (Discord ho orizne do kruhu), avatar-512.png (bot, webhooky),
              banner-960x540.png (banner serveru / pozvanky)

Koruna je prekreslena do vektoru z puvodniho loga. Vse se generuje skriptem tools\brand\brand.ps1 v repozitari.
