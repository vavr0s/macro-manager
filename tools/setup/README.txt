MACRO MANAGER - SETUP
=====================

1. Extract the whole ZIP to any folder (right-click - Extract All).
2. Double-click "Install Macro Manager.bat".
3. Allow the administrator prompt (the app always runs as administrator).
4. Choose where to install, answer the shortcut questions - done.

Nothing else is needed: the AutoHotkey runtime is included (folders runtime64 / runtime32,
free software under GNU GPL v2, see AutoHotkey-license.txt). It is only used for the setup;
the installed app gets its own "Macro Manager.exe". After the installation you can delete
the extracted folder.

Windows may show "Windows protected your PC" (SmartScreen) or "unknown publisher" because
the files are not signed: choose "More info" - "Run anyway" (Yes in the administrator prompt).
If you downloaded the ZIP, you can also right-click the ZIP - Properties - tick "Unblock"
before extracting.

Uninstall: inside the app (Uninstall button) or Windows Settings - Apps.
