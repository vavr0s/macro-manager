## welcome
# 👋 Welcome to ComboCrown
**ComboCrown** (formerly Macro Manager) is a free Windows app for game macros – skill rotations, combos and key sequences, set up in a few clicks, no vendor mouse/keyboard software needed. Made for **4Story** players (4Classic and other servers), but it works in any game.

**How to start**
1. Download the installer from **<https://combocrown.com>** (more in <#download>)
2. Run it and choose a folder – the app installs itself and starts
3. Click **Add**, set the **trigger key**, pick the game in **Only in app**, tick the macro – done
4. Ready-made macros: open **Macro Hub** in the app (button next to the search box) or look in <#macro-sharing>

Questions → <#faq> · Problems → <#create-ticket> · Rules → <#rules>

## faq
# ❓ FAQ
**Is this the old Macro Manager?**
Yes – Macro Manager was renamed to **ComboCrown** in version 1.24. Just update, your macros and settings stay.

**Is it allowed in 4Story / 4Classic?**
4Classic supports combat macros – the game has its own Macro Builder since the December 2024 patch. Macros for **farming / AFK / botting are bannable** (4Classic rule 4.8). Use ComboCrown for combos and rotations and follow the rules of your server – it's your responsibility.

**Why does it ask for administrator rights?**
Games usually run as administrator; Windows only lets keys from a program with the same rights reach them.

**My antivirus or browser complains.**
The app is not code-signed, so some antiviruses and browsers are careful with it. The whole source code is public on GitHub. You can also check the file on <https://www.virustotal.com>.

**How do I update?**
Green arrow in the app → click → done. Your macros stay.

**Where are my macros? New PC?**
In the `config` folder next to the app. Use **Backup...** in the app to save everything into one file and restore it anywhere.

**The macro does nothing in the game.**
Check that the macro is ticked, **All macros** is on, **Only in app** matches the game (use **Select**). If the game misses keys, raise the delays a little.

**Something else?** Open a ticket in <#create-ticket>.

## macro-sharing
# 🎮 How to share a macro
**Easiest: Macro Hub in the app**
1. Click the **share icon** at the end of the macro's row → fill in the name, the game and a description → **Share**
2. Others find it in **Macro Hub** (button next to the search box), see what it does and download it with one click
3. When you improve your macro, the app offers to update it in Macro Hub – players who downloaded it get a notice

**Or post it here**
1. Select the macro → **Export...** (or drag it out of the list onto the desktop)
2. **New post** here → title = what it does, pick the **class** and **type** tags → attach the `.ahk` file → describe keys, skills and delays
3. Others: download the file and **drop it onto the ComboCrown window** – it's added switched off, ready to edit

Only macros made in ComboCrown. No farming / AFK macros (<#rules>).
