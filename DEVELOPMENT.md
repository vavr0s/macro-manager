# Development

The app is distributed (and updates itself) as one file, `Macro Manager.ahk` in the repository root.
That file is **built** - do not edit it directly.

- `src/*.ahk` - the source, split by topic. `tools/build.py` joins the files in name order into one script
  (`00_startup.ahk` holds the auto-execute part and must stay first).
- `src/90_embedded_images.ahk` - icon, logo, flags... as base64.
- `src/99_translations.ahk` - generated by `i18n/gen_tables.py` from `i18n/cs.json`, `pl.json`, `de.json`
  (English text is the key, see `i18n/keys.json`). `i18n/check.py <lang>` checks placeholders / line breaks.

- `src/28_library.ahk` - the macro library panel; its web service is in `server/` (Cloudflare Worker + D1, see
  `server/README.md` - deploy and moderation of reported macros).
- `i18n/extract_keys.py BUILT_FILE` collects new texts into `i18n/keys.json`; add them to `cs.json` / `pl.json` /
  `de.json`, run `i18n/check.py <lang>` and `i18n/gen_tables.py`.

Release channels: branch `main` = stable, branch `beta` = test builds (own registry keys, "(beta)" label).

## Building a release

- `tools/notes.json` - release notes of the version, one line per change in en / cs / pl / de.
- Beta: `build.py plain.ahk`, `make_beta.py plain.ahk "Macro Manager.ahk"` (own registry keys / folder / shortcuts,
  "(beta)" labels, update channel `beta`, white icon from `tools/beta_icon.b64`), then
  `set_notes.py X.Y.n --beta` (version + notes into the app and `version.json`, with the SHA-256).
- Stable: `build.py "Macro Manager.ahk"`, then `set_notes.py X.Y --src`.
- Setup packages: `package.py "Macro Manager.ahk" --runtime DIR --out DIR [--ahk2exe Ahk2Exe.exe]` writes
  `MacroManager[-Beta]-Setup.zip` and, with Ahk2Exe (Windows), the one-file installer `.exe`
  (`tools/setup/installer_stub.ahk`). The runtime folder (`runtime64`/`runtime32` = renamed AutoHotkey 2.0.19
  + licence) is not in the repository - take it from the last setup zip.
- Website: `site/` (one page, EN/CS/PL/DE in the page script). After a stable release build the stable packages,
  then `deploy_site.py --dist DIR` puts the page + `MacroManager-Setup.exe/.zip` (under `/download/`) on
  https://macro-manager.vavr0smacromanager.workers.dev (Cloudflare Worker with static assets, wrangler logged in).
  `--dry DIR` only assembles the folder for a local preview.
